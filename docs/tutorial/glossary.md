# 查询术语、文件与操作位置

本页用于快速确认教程中的术语、包类型和命令位置。需要具体步骤时，从表格进入相应章节。

## 区分主机与设备

| 名称 | 含义 | 典型操作 |
| --- | --- | --- |
| Ubuntu 开发主机 | 保存源码和工具的电脑或虚拟机 | 构建、打包、验签 |
| 小咪/板端 | 运行目标产品系统的设备 | 触屏操作、读取日志 |
| 管理电脑 | 运行管理浏览器的电脑 | 登录设备 IPKVM |
| 被控电脑 | 提供 HDMI 并接收 USB HID 的电脑 | 显示和输入测试 |
| 文档主机 | 构建静态教程站的主机 | `npm run build` |

这些角色可共用物理电脑，终端连接目标仍应分别确认。

## 区分版本与兼容条件

| 术语 | 含义 | 查询入口 |
| --- | --- | --- |
| 应用版本 | 桌面发布线的版本 | [桌面构建](build-app.md) |
| 系统版本 | 内核、平台服务和基础环境版本 | [系统构建](build-system.md) |
| APP 版本 | 某个用户扩展的 manifest 版本 | [用户 APP](user-app.md) |
| ABI | 二进制与加载器、运行库的接口约定 | [架构](architecture.md) |
| IPC / Ports | 进程间通信与版本化平台接口 | [架构](architecture.md) |
| Provider | 将统一接口连接到具体平台的实现 | [平台适配](source-map.md) |
| SDK / sysroot | 构建工具和目标头文件、库等输入 | [开发环境](environment.md) |
| 完整目标条目 | 产品、板型/修订、ABI、接口等一组兼容条件 | [更新](ota.md) |

## 识别常用文件

| 文件 | 用途 | 不能单独说明的结果 |
| --- | --- | --- |
| `.aitapp` | 用户扩展安装包 | 整个桌面或系统已升级 |
| `application.tar.gz` | 独立桌面载荷 | 已完成签名和实机验收 |
| `.img.gz` | 压缩的完整系统镜像 | 适用于任意同 SoC 板卡 |
| `.swu` | 系统 OTA 载荷 | 当前设备已具备匹配 A/B 基线 |
| `SHA256SUMS` | 校验附件一致性 | 文件来源可信或板型兼容 |
| `manifest.json` | 包身份、目标、版本等声明 | 未经签名与校验即可安装 |
| `sdk-lock.json` | SDK 输入锁定 | 任意 SDK 均等价 |
| `BUILD-COMPLETE` | 对应构建流程完成 | 产品已发布或设备已验收 |

## 理解联网与控制术语

| 术语 | 在本项目中的含义 |
| --- | --- |
| IPKVM | 通过网络查看 HDMI 画面并发送键鼠 |
| WebRTC | 浏览器视频与 DataChannel 传输机制 |
| HID | USB 键盘、鼠标等标准输入设备协议 |
| MCP | 宿主发现并调用截图、输入等工具的协议 |
| A2DP Sink | 接收手机蓝牙音频的一端 |
| AVRCP | 蓝牙播放控制和媒体信息协议 |
| DP | 涂鸦功能数据点，包含类型、权限和取值 |
| PID / License | 涂鸦产品模型标识 / 设备身份授权；用途不同 |
| A/B OTA | 使用双系统槽位及启动恢复机制的在线更新 |

## 解释示例中的占位值

`DEVICE_SERIAL` 替换为已授权目标的 ADB 序列号；`192.168.1.50` 替换为板端 IP；`203.0.113.10` 为保留公网地址示例；`*.example.com` 替换为实际服务域名；`/absolute/path/...` 和 `REPLACE_WITH_...` 替换为本次受控输入。

命令返回退出码 0 通常表示该命令完成，具体结果仍按步骤检查。操作出现错误时先处理当前步骤，不将示例输出当作实际执行证据。
