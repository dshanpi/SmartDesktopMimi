# 完成首次启动与基本检查

适用于已安装配套系统的设备。本章在触屏和管理电脑上完成版本登记、联网、基本交互及首次功能检查，无需编译程序。

## 准备首次检查

准备 Wi-Fi 名称与密码、固件交付说明，以及用于记录结果的本地文件。若需要网页管理，准备与设备网络互通的电脑。先完成[硬件连接](hardware.md)。

## 启动到可操作的桌面

1. 启动设备，观察启动图到桌面的切换。
2. 等待首页内容加载后，点击应用入口。
3. 使用页面返回入口回到首页。
4. 再次打开另一页面，确认输入持续响应。

**检查结果：** 桌面可进入、操作和返回。停在启动图、黑屏或触摸无响应时，保留串口和启动日志，按[故障排查](troubleshooting.md)处理后再继续。

## 记录设备与软件版本

在设置和更新相关页面查看版本，结合交付清单填写以下记录。应用版本与系统版本分别填写；页面未显示的信息由管理员读取对应清单。

| 记录项 | 填写内容 |
| --- | --- |
| 实物板型与修订 | PCB 上的实际标识 |
| 产品版本 | public / private，按交付说明 |
| 系统版本 | 安装的系统版本 |
| 桌面应用版本 | 当前实际运行版本 |
| 安装文件来源与 SHA-256 | 引用本次交付清单 |
| 板端 IP | 联网后填写 |
| 检查时间与结果 | 各操作的实际结果 |

无法确认版本时，先保持当前系统，查清来源后再考虑升级。

## 连接网络并核对时间

1. 从首页打开**无线网络**，开启 Wi-Fi。
2. 扫描并选择目标网络，输入密码，提交一次连接请求。
3. 等待实际连接状态更新，记录获得的 IP。
4. 在管理电脑访问设备地址，或按[网络检查](network.md)核对地址、路由和目标服务。
5. 检查设备日期与时间，按该固件提供的时间同步方式校正。

网络连接与网页访问分别检查。若 HTTPS 或云服务报证书错误，先核对设备时间再继续排查。

## 检查导航和设置保存

1. 在首页应用区左右滑动，确认应用页及分页指示同步变化。
2. 打开**设置**，修改一个易于观察的项目，例如音量。
3. 等待保存反馈，再返回首页。
4. 重新进入设置，核对刚修改的值。
5. 打开**用户应用**；没有安装 APP 时，应显示空列表或空状态，仍可正常返回。

若显示“未确认保存”或等待状态，按页面提示重试并核对后端状态。小屏设备同时检查滚动区域，确保返回及底部按钮可操作。

## 验证需要使用的功能

按用途选择一项继续，不必一次启用所有服务：

| 用途 | 操作教程 | 本次检查结果 |
| --- | --- | --- |
| 播放手机声音 | [连接蓝牙音频](bluetooth.md) | 实际出声，暂停和重连可确认 |
| 查看并控制电脑 | [使用 IPKVM](ipkvm.md) | 视频、键盘和鼠标分别通过 |
| 使用语音对话 | [使用涂鸦助手](ai-iot.md) | 符合授权条件，完成一次语音回复 |
| 查看智能设备 | [使用涂鸦智家](iot.md) | 设备状态可读，控制结果可刷新核对 |
| 安装自定义 APP | [制作与安装 APP](user-app.md) | 安装版本正确，界面及返回可用 |

## 保存首次使用记录

将版本、IP、导航结果、设置保存结果和所选功能的结果保存在同一份记录。出现异常时写明操作与提示，不用“正常”代替具体结果。

完成本章后，可进入[桌面日常操作](desktop.md)。涉及后续升级时，另执行[备份](settings-data.md)和[更新检查](ota.md)。
