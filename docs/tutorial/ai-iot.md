# 涂鸦、IoT 与设备配对

先确认产品版本，再判断功能是否应该可用。公共桌面、涂鸦设备自身授权、普通 IoT 云项目接入、100ask 账号配对是不同链路。

## 四类能力的区别

| 能力 | 作用 | 前提 |
| --- | --- | --- |
| 公共桌面和普通应用 | 本机交互、用户应用、通用更新 | 兼容的系统与平台服务 |
| 涂鸦助手 / 自由对话 | 设备自身接入涂鸦语音服务 | 私有适配、有效设备 License、网络 |
| 通用涂鸦 IoT | 连接云项目，显示设备并使用 DP 控制 | 项目、账号、设备和权限配置 |
| 100ask 一机一码 / 自动配对 | 设备与账号归属关联 | 私有适配及合法工厂身份 |

公共系统不会因填入一串 UUID 就变成私有系统。私有程序、来源锁与运行时授权共同决定能力；桌面程序仍然共享同一份公开源码。

## 使用已授权的涂鸦助手

1. 确认设备由提供方完成合法的逐台授权；不要把别的设备 License 拷贝过来。
2. 完成 Wi-Fi 和系统时间检查，打开助手页面。
3. 根据实际固件选择对话模式或进入自由对话；观察聆听、识别、回复和错误状态。
4. 检查麦克风输入、扬声器和音量；先验证一次短对话，再做长时间测试。
5. 退出后确认回到桌面，状态没有卡在持续聆听或回复中。

原始手册记录了“你好涂鸦”唤醒与自由对话交互；具体唤醒词、语言和退出手势以该设备固件的说明为准。旧图和某次对话成功不证明所有麦克风、AEC、云端和打断场景已通过。

## 设备绑定页如何判断

页面应区分 **已绑定、未绑定、状态未知**。已经绑定时没有新的绑定码是可能的正常结果；不能据此清除身份、重新 provision 或解绑。

- 未绑定：按页面提供的有效码和有效期操作。
- 已绑定：查看绑定状态，需要时手动重新查询。
- 未知或请求失败：先查网络和接口响应，保留原有身份。
- 过期：请求新的有效码，不使用截图里的历史码。

不要把绑定二维码、设备签名、secret 或授权文件截图发到公共仓库。

## 使用通用 IoT

IoT 页有界面不代表已经配置真实云项目。先按项目手册准备区域、账号授权和设备；确认设备列表更新，再测试一个低风险 DP，例如查询状态。写入前核对 DP 类型、取值范围及返回结果，不把“请求已发送”当作设备已执行。

项目缺失时应显示未配置/空状态；接口失败时应提供错误与重试反馈。开发快照的界面渲染通过，不替代真实设备控制验收。

## 数据保存在哪里

私有版逐台 License 在运行时注入，历史布局包括 `/factory/tuya/license.env`，并通过 `/overlay/factory/tuya` 持久化；云身份与绑定数据有各自保护路径。查看权限或存在性即可排查大部分问题，不要 `cat` 密钥正文到共享终端。

生产注入脚本位于私有仓库，公开仓库里的历史说明不是授权材料。通用镜像和 Git 都不包含真实 UUID/AuthKey、签名私钥或工厂数据库。
