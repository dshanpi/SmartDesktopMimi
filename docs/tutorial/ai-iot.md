# 使用涂鸦助手与自由对话

本章适用于已交付涂鸦私有适配和逐台授权的设备，完成一次语音对话及退出检查。公共系统的共享桌面不包含涂鸦设备授权；是否可用先以产品交付说明和页面状态为准。

## 检查服务前提

开始前确认：设备已联网、系统时间正确、麦克风和扬声器可用，设备提供方已完成本机授权。涂鸦语音服务与[100ask 账号配对](pairing.md)、[涂鸦智家](iot.md)分别配置。

| 条件 | 检查方式 | 未满足时 |
| --- | --- | --- |
| 产品包含涂鸦适配 | 查交付说明和助手状态 | 使用对应产品版本，向交付方确认能力 |
| 本机授权有效 | 由管理员检查授权存在性与服务反馈 | 按逐台授权流程处理 |
| 网络和时间可用 | 完成[网络检查](network.md) | 先恢复联网和时间同步 |
| 音频输入/输出可用 | 检查设备音量与音频服务 | 处理音频故障后再测试对话 |

## 完成一次短对话

1. 在首页打开**涂鸦助手**，等待服务状态加载。
2. 按交付固件提供的入口启动对话。支持唤醒词的版本可按随设备说明唤醒；历史手册使用“你好涂鸦”。
3. 说出一个简短、易于核对的请求。
4. 观察聆听、处理和回复状态，等待播放结束。
5. 检查回复声音与页面状态是否对应，再进行下一次请求。

**检查结果：** 能够进入聆听，完成请求并播放回复，最终退出本次处理状态。只显示连接成功时，仍需完成一次实际对话。

## 使用自由对话并退出

1. 在支持该功能的固件中进入自由对话。
2. 说出第一条请求，等待回复完成后继续下一轮。
3. 使用当前页面提供的结束或退出操作。
4. 回到桌面，确认没有停留在持续聆听或回复状态。

具体退出手势以交付版本为准。多轮交互、打断和回声处理应按实际场景分别检查，不能由一次回复推断全部完成。

## 根据状态处理异常

| 现象 | 检查顺序 |
| --- | --- |
| 未授权或授权错误 | 核对产品版本 → 本机授权 → 服务错误；由管理员处理 |
| 持续连接中 | 检查 Wi-Fi、目标服务、时间，再保留后端日志 |
| 能进入聆听但不识别 | 检查麦克风输入及相应音频服务，再短测一次 |
| 显示回复但无声 | 检查设备静音、音量与扬声器输出 |
| 退出后状态未释放 | 记录时间、页面和进程状态，停止重复发起会话并排障 |

授权文件可能位于 `/factory/tuya/license.env`，并通过 `/overlay/factory/tuya` 持久保存。管理员排查时优先检查文件存在性、权限和脱敏错误；真实 UUID/AuthKey 不进入截图、日志分享或公共仓库。

## 区分语音授权与云端功能模型

设备 License 用于设备身份接入。手机涂鸦面板可显示哪些控制项，还取决于产品 PID 的 DP 定义。出现 `2/14 DPs` 时，先由产品管理员核对云端模型，而不是替换本机 License。

DP 配置属于产品维护，详见[涂鸦智家与 DP 检查](iot.md)。本章完成后，保留语音输入、回复、退出及异常提示的实际结果。
