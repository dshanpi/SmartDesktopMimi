# 查询绑定状态并完成账号配对

本章用于支持 100ask 一机一码或自动配对能力的私有产品。配对将设备与账号关联；操作前确认正在管理的是目标设备和正确账号。

## 准备配对条件

设备应具有合法工厂身份，网络和系统时间正常。准备交付说明指定的账号及配对入口。公共产品没有这项私有能力时，不通过复制其他设备凭据启用。

## 先查询当前状态

1. 打开设备当前固件提供的配对页面。
2. 等待状态查询完成，读取页面的绑定结果。
3. 根据结果选择下列操作。

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 已绑定 | 服务已返回绑定关系 | 核对当前归属或联系管理员；无需新的绑定码 |
| 未绑定，且有有效码 | 可以继续本次配对 | 按配套账号入口提交有效码 |
| 绑定码已过期 | 当前码不能继续使用 | 重新查询并取得有效码 |
| 未知、超时或查询失败 | 当前无法确认绑定关系 | 检查网络与服务，再查询 |

“没有绑定码”本身不能用于判断是否未绑定。已有后台绑定的设备可能正常返回已绑定状态而不生成新码。

## 使用有效码完成配对

1. 确认页面处于未绑定状态，并显示本次有效码和有效期。
2. 在交付说明指定的配对入口登录目标账号。
3. 按页面要求输入或扫描当前有效码，核对设备信息后提交。
4. 返回设备配对页，主动重新查询一次。
5. 确认服务返回已绑定状态，再退出页面。

**检查结果：** 设备查询已确认绑定。账号侧显示提交成功后，仍需执行设备侧读回。有效期内未完成时，刷新取得新码，避免使用历史截图中的码。

## 处理失败并保留身份

- 查询超时：检查[网络与时间](network.md)，保留错误和发生时刻后重试。
- 账号归属不符：由设备或账号管理员按正式转移流程处理。
- 已绑定却无新码：核对绑定关系，无需重复初始化设备身份。
- 状态未知：保持现有身份与绑定数据，等待服务返回明确结果。

重新 provision、解绑和恢复出厂会影响不同数据，均需使用对应维护流程。普通连接失败不通过删除工厂身份文件处理。

## 保存完成记录

记录设备型号、固件版本、操作时间、查询前后状态和脱敏结果。绑定二维码、设备签名、secret 和完整有效码不放入公共记录。

配对成功后，继续验证所需业务功能；账号绑定不自动证明语音、IoT 控制或 OTA 已通过。
