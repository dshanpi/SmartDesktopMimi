# 操作桌面与内置应用

桌面提供状态展示、应用入口和设备设置。当前开发快照以首页内应用区和组件化布局为主；较早版本有不同的应用列表与底部导航，操作时以实际固件为准。

## 首页怎么用

首页上方保留助手、HDMI 等主要区域；应用区在首页内横向分页。点图标打开应用，左右滑动选择其他应用；页码提示采用随页数生成的短横线。它不是只有一个按钮的抽屉，也不要求先进入全屏应用列表。

状态栏反映网络、音量、云端或更新状态。图标显示“连接”时仍应在对应功能页检查详情；它不保证所有网络服务都正常。

## 常用入口与操作目标

| 入口 | 常见操作 | 成功时应看到 |
| --- | --- | --- |
| 无线网络 | 扫描、选择和连接 | 状态更新并取得地址 |
| 蓝牙音频 | 配对、连接、播放控制 | 连接状态和可用媒体信息 |
| HDMI 控制 | 按需启用/关闭预览 | 信号或无信号状态明确 |
| 涂鸦助手 | 查看对话和绑定状态 | 符合当前产品授权的入口 |
| 涂鸦智家 | 查看设备和控制项 | 真实项目配置提供的设备/状态 |
| 用户应用 | 刷新、选择和打开扩展 | 已安装列表或明确空状态 |
| 系统更新 | 检查版本、查看候选 | 当前状态、可用性与失败原因 |
| 设置 | 显示声音、外观语言、设备更新 | 修改结果与保存状态 |

普通应用与系统应用的行为不同：“用户应用”中的内容来自已安装 `.aitapp`，不是扫描任意 Linux 可执行文件。

## 修改设置的正确反馈

点击修改后，留意请求是否发送成功、是否在等待后端、是否已保存。网络或后端异常时，页面可能允许“稍后处理”并保留未保存状态；返回页面不代表保存成功。

小屏布局将设置分类并允许滚动。修改亮度或音量后返回再进入，检查值是否保留。涉及主题、语言和横向布局的修改，还应确认文字可读、按钮可达。

## 遇到空页或错误状态

- 用户应用列表为空：先确认真的安装过 APP，再点击刷新；不需要为了刷新而重启整机。
- 涂鸦智家没有设备：检查云项目和账号条件，不先修改设备身份。
- HDMI 无信号：检查被控电脑输出和线缆；空状态不等于桌面崩溃。
- 更新一直等待：检查网络、后端是否响应、当前更新事务；不要连续重复点安装。
- 蓝牙断开仍显示等待：等待实际状态确认，超时后再检查服务日志。

## 控制范围

SDK、板型、交叉编译器、分辨率构建参数和 deb/Tina 选择属于开发主机工具，不应出现在普通用户桌面中。它们在[开发环境](environment.md)与[构建章节](build-app.md)配置。

新版页面的主机渲染与输入回放已经有记录，但真实触摸和目标新固件验收仍需单独完成。依据：[全页补全记录](https://github.com/dshanpi/SmartDesktopMimi/blob/75500c76e389971bfb3bd0a45ac4bed74e1f8cfa/docs/validation/quality076-pages-completion-20261028.json)、[构建与截图范围](https://github.com/dshanpi/SmartDesktopMimi/blob/75500c76e389971bfb3bd0a45ac4bed74e1f8cfa/docs/validation/quality076-pages-completion-build-20261028.json)。
