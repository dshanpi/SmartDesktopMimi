# 操作桌面、应用与设置

本章说明首页导航、常用应用入口及设置保存方式。操作依据固定开发快照；旧交付固件的应用排列可能不同，可结合[界面参考](gallery.md)识别。

## 打开应用并返回首页

1. 在首页应用区横向滑动，查看其他页。
2. 点击应用图标，等待页面内容或明确的加载状态出现。
3. 使用该页面的返回入口回到首页。
4. 需要切换应用时，返回后再打开下一个入口。

开发快照的首页保留上方主卡片，应用区直接位于首页内；分页使用短横线显示当前位置。打开错误应用或返回无效时，记录实际点击位置、目标页面和版本，停止重复点击并查[故障排查](troubleshooting.md)。

## 根据任务选择入口

| 入口 | 完成的操作 | 查看什么结果 |
| --- | --- | --- |
| 无线网络 | 开启、扫描和连接 Wi-Fi | 实际连接状态及地址 |
| 蓝牙音频 | 允许手机连接并播放声音 | 连接状态、手机输出与实际声音 |
| HDMI 控制 | 按需开启或关闭采集/预览 | 有信号、无信号或关闭状态 |
| 涂鸦助手 | 语音对话及服务状态 | 聆听、处理、回复和错误反馈 |
| 涂鸦智家 | 刷新设备、查看功能和发送指令 | 设备在线状态与刷新后的实际值 |
| 用户应用 | 浏览并打开已安装 `.aitapp` | 应用列表、版本及运行结果 |
| 系统更新 | 检查更新与查看处理状态 | 当前版本、候选和拒绝原因 |
| 设置 | 修改声音、显示、外观和语言 | 保存反馈及重新进入后的值 |

只有已交付且配置完成的能力才能正常使用。入口存在但显示未配置时，按对应服务章节补齐条件。

## 修改显示和声音

1. 打开**设置**，进入显示与声音相关分类。
2. 调整音量或亮度，观察实际变化。
3. 等待页面确认保存；显示未保存或重试提示时，按提示处理。
4. 返回后重新进入，确认数值仍为设置值。

完成即时检查后，如需验证重启保留，应在维护窗口按[数据检查](settings-data.md)另外记录。页面值改变、实际硬件变化和持久保存是三个检查点。

## 修改外观与语言

1. 在**设置 → 外观与语言**选择可用主题或语言。
2. 检查标题、按钮和长文本是否正常显示。
3. 返回首页再打开常用应用，检查语言是否一致。
4. 用户 APP 有独立本地化资源时，关闭后重新打开以加载对应入口。

小屏设备需检查页面滚动、返回栏和确认按钮是否可达。发现文字遮挡时保留该页面截图及分辨率。

## 处理常见页面状态

| 页面反馈 | 含义 | 下一步 |
| --- | --- | --- |
| 正在加载或等待上一请求 | 当前请求尚未完成 | 等待结果；持续不返回时记录时间并查后端 |
| 用户应用为空 | 尚无可显示的已安装 APP | 在 Applications 核对安装结果后刷新 |
| 智家未配置或需授权 | 服务配置或账号条件不足 | 按[智家配置](iot.md)由管理员处理 |
| HDMI 无信号 | 采集端未取得有效输入 | 检查输出电脑、HDMI 接线及输入状态 |
| 未确认保存 | 当前值的持久化尚未确认 | 重试保存并重新进入核对 |
| 更新被拒绝 | 某项安装条件不满足 | 查看原因，按[更新流程](ota.md)处理 |

## 结束日常操作

退出不用的远程控制会话，停止 AI 任务，并关闭不需要的 HDMI 采集。设置修改后确认保存完成，再执行计划中的关机或维护操作。

开发工具链、板型和编译参数在 Ubuntu 主机配置，入口见[开发环境](environment.md)。
