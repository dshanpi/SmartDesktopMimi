# 授权智家服务并控制设备

“涂鸦智家”用于查看已授权智能设备及其可用控制项。本章先完成账号与服务条件，再执行设备刷新、单项控制和结果读回。产品自身涂鸦面板的 DP 配置在本章末尾单列。

## 准备账号与设备

1. 在智能生活 App 中添加目标设备，确认手机端能读取状态。
2. 由管理员完成智家服务的云项目、账号及设备授权。
3. 确认小咪已联网，运行的固件包含智家客户端。
4. 准备一个可以安全测试、结果易观察的设备控制项。

手机侧已添加设备后，仍需完成小咪所用智家服务的账号授权。涂鸦助手的单机 License 不代替这项授权。

## 管理员配置客户端连接

固定源码中的客户端读取 `/etc/smartdesktopmimi/iot-client.json`，连接管理员部署的 HTTPS 智家服务。该文件仅包含两个字段：

```json
{
  "endpoint": "https://iot.example.com",
  "token": "REPLACE_WITH_ACCOUNT_SCOPED_SERVICE_TOKEN"
}
```

这是结构示例。使用前替换为实际服务源地址和账号范围内的受限令牌；不能直接将涂鸦 Access Secret 填入此处。客户端会在源地址后追加 `/v1/devices` 等路径，因此 `endpoint` 不包含路径、查询参数或末尾 `/`。

客户端要求配置为非符号链接的普通文件，属主与客户端进程有效用户一致，组及其他用户没有访问权限；文件长度为 2–4096 字节。令牌只接受字母、数字、`-`、`_`，长度 32–200。上述示例值没有实际访问能力。

由部署管理员按系统服务用户写入配置，在**板端 shell**检查元数据：

```sh
ls -l /etc/smartdesktopmimi/iot-client.json
```

检查属主与类似 `-rw-------` 的权限；避免把文件正文输出到共享终端。更新配置后回到智家页面刷新。服务端部署和授权输入由该服务提供方交付，公开客户端源码不包含可直接使用的云账号。

## 刷新已授权设备

1. 从首页打开**涂鸦智家**。
2. 点击**刷新设备**，等待请求完成。
3. 查看在线数量、设备名称和在线/离线状态。
4. 点击目标设备，读取可用控制项。

**检查结果：** 设备列表与授权范围一致，目标设备状态可读。列表为空时，先核对手机账号授权；页面至多显示前 100 个设备。

| 提示 | 处理 |
| --- | --- |
| 连接你的智能生活 / 尚未连接智家账号 | 由管理员检查服务配置与账号授权 |
| 需要重新授权 | 更新账号授权后刷新，保留现有设备配置 |
| 暂时无法连接 | 检查网络、服务可达性与响应格式 |
| 还没有已授权的设备 | 核对智能生活账号与授权设备范围 |
| 当前授权为只读 | 查看状态；需要控制时由管理员调整授权 |

## 发送一个控制指令

1. 打开在线设备，选择一个受支持的功能。
2. 布尔值选择开/关；整数通过加减按钮选择合法范围和步长；枚举选择允许值。
3. 点击**设置此项…**，核对确认框中的功能和目标值。
4. 点击**确认发送**一次，等待响应。
5. 点击**刷新设备状态**，同时观察设备实际行为。

**检查结果：** 刷新后的状态和实际设备行为与目标值相符。页面显示“指令已受理，尚未确认设备状态”时，操作仍需要读回；未确认受理结果时先刷新，避免重复下发。

当前客户端支持 `Boolean`、`Integer`、`Enum` 控制项。功能定义不合法、设备离线或授权只读时，应先解决相应条件。

## 产品管理员核对小咪自身 DP 模型

这一流程用于涂鸦手机面板控制**小咪自身**，与上面的智家设备列表分开。DP（数据点）描述云端功能的类型、权限和取值。

1. 由 PID 所有者在涂鸦平台核对当前产品的 DP 定义。
2. 按项目机器清单配置功能并导出实际 Schema JSON。
3. 在 **Ubuntu 开发主机、固定产品源码根目录**执行，替换导出文件路径：

```sh
python3 scripts/validate_tuya_dp_schema.py /absolute/path/to/actual-schema.json
```

检查输出包含全部 14 个必需 DP 通过；缺项或类型/范围不符时先修改云模型，再复验。常用项目如下，完整清单见文末依据：

| DP | 功能 | 类型/范围 |
| --- | --- | --- |
| 1 / 3 | 助手开关 / 音量 | bool / 0–100 |
| 101 / 102 / 103 | 屏幕亮度 / HDMI / 蓝牙 | 20–100 / bool / bool |
| 104 / 105 | 状态灯开关 / 亮度 | bool / 0–100 |
| 106–110 | 温湿度、电压、电流、功率 | 只读，单位与缩放按 Schema |
| 111 / 112 | 助手状态 / 自由对话 | 只读 enum / bool |

4. 按产品维护流程应用云端配置，在设备助手页检查 DP 覆盖率。
5. 对可写项逐项检查动作与真实回显，对只读项检查更新；HDMI 测试结束关闭采集。

需要刷新云模型时按账号管理员的流程处理，保留现有身份和绑定数据。Schema 通过说明定义一致，真实设备动作仍需单独验证。
