# 智能桌面小咪商业化执行计划

> 内部工作稿，版本 V1.0，2026-09-14。价格仅用于建立核算方法，不构成对外报价。

## 推荐战略

采用“B2B 解决方案先行 + 自有品牌样板机”的双轨模式：

- 用“智能桌面小咪”展示完整体验、积累真实用户反馈和建立品牌认知。
- 优先向 AI 玩具、礼品、智能硬件和行业终端品牌销售白牌/OEM 方案。
- 用样机费、NRE 和首批订单覆盖产品化投入，避免一开始承担消费品牌获客与库存压力。

第一阶段不把儿童市场作为唯一入口。儿童陪伴具有吸引力，但内容、隐私、监护人
同意和售后责任更高；可先从成人桌面助手、品牌礼赠、展厅和办公场景获取订单。

## 收入结构

| 收入项 | 收费单位 | 说明 |
|---|---|---|
| 开发样机 | 套 | 覆盖硬件、烧录、测试资料和基础支持 |
| NRE 定制费 | 项目 | UI、声学、外设、App、角色、知识和结构适配 |
| 硬件供货 | 台/批 | 主板、套件或完整整机 |
| 软件授权 | 台 | Smart Desktop Mimi OS、量产工具和约定功能版本 |
| AI/云服务 | 月、年或额度 | 涂鸦服务、模型调用、存储、消息与运营成本 |
| 维护 SLA | 年 | OTA、安全修复、故障诊断、版本支持和响应时效 |

## 报价方法

对外报价前先形成可审计的单台完全成本：

```text
单台完全成本 = BOM
             + PCBA/组装/测试
             + 包装与物流
             + License 与预计 AI 云成本
             + 认证和模具摊销
             + 质保与返修准备金
             + 渠道及税费
```

建议把样机、NRE、量产硬件、软件授权和云服务分别报价，避免客户把持续云成本理解为
一次性硬件成本。以下区间只用于首次商务沟通，正式数字必须在 BOM 和服务合同冻结后
重新核算：

- 开发样机：建议零售价 `¥1,999～3,999/套`。
- 标准方案：基础项目接入费 + 批量硬件价格 + 每台软件授权。
- 品牌定制：按需求评估 NRE；结构、声学、App 上架和定制唤醒模型分项报价。
- 云服务：设置基础额度和超额计费，不承诺无限对话。

## 首批目标客户

按优先级寻找：

1. 已有销售渠道、但缺少 Linux/AI 团队的智能硬件品牌。
2. 需要快速推出 AI 礼赠品或桌面终端的方案公司。
3. 有展厅、门店、酒店、办公接待场景的行业集成商。
4. 有内容、角色 IP 或知识服务，但缺少硬件载体的公司。

客户筛选原则：拥有明确场景、愿意支付样机或 NRE、能说明预估销量，并接受标准平台
边界。只要求免费 Demo、没有销售计划且持续改变需求的客户不进入定制开发。

## 120 天路线

### 第 1～30 天：商品定义

- 冻结标准 SKU 的主板、屏幕、麦克风、扬声器、电源和外壳方案。
- 建立 BOM、供应商、替代料和停产风险清单。
- 完成 20 台工程样机所需工装与一机一密流程。
- 确定标准版功能、可选项、明确不支持项和售后边界。
- 完成方案 PDF、演示素材、客户需求表和初版合同附件。

### 第 31～60 天：工程样机与客户验证

- 生产并编号 20 台工程样机。
- 完成 72 小时稳定性、100 次启动、断网重连和 OTA 异常测试。
- 向 3～5 家目标客户收费试用，记录部署、对话和故障数据。
- 根据真实反馈冻结第一个标准面板、角色和 UI 配置。

### 第 61～90 天：小批量准备

- 修正声学结构、电源、温升和组装一致性问题。
- 建立工厂测试工位、烧录版本管理和出货检验记录。
- 完成无线、电源、EMC 和销售地区合规预评估。
- 冻结包装、说明书、隐私政策、用户协议和售后恢复流程。

### 第 91～120 天：百台试产

- 执行 100 台左右试产和抽检老化。
- 追踪激活率、联网率、对话成功率、故障率和售后原因。
- 选择一个付费客户形成可公开案例。
- 根据退货和服务数据决定是否开模、扩大库存或继续方案化销售。

## 经营与质量指标

| 指标 | 用途 |
|---|---|
| 样机转付费项目率 | 判断客户定位和销售材料是否有效 |
| 单台完全成本与毛利 | 防止只计算 BOM、忽略云服务和售后 |
| 首次配网/绑定成功率 | 衡量用户开箱体验 |
| 7/30 天设备在线率 | 衡量 Wi-Fi、MQTT 和后台稳定性 |
| 对话完成率与中断原因 | 衡量音频、AEC、网络和服务端体验 |
| OTA 成功/回滚率 | 衡量规模维护风险 |
| 返修率与平均处理时长 | 衡量硬件一致性和售后成本 |
| 每活跃设备月均云成本 | 决定订阅套餐与免费额度 |

## 必须形成的销售与交付资料

- 一页产品简介和完整方案 PDF。
- 60 秒演示视频；视频制作前可先使用本目录图片分镜。
- 三档能力与报价表。
- 客户需求确认表、项目范围表和变更单。
- BOM、认证矩阵、工厂测试规范和出货检查表。
- 软件版本、第三方许可、隐私与数据流说明。
- 质保范围、远程诊断、返修和 OTA 支持协议。

## 品牌建议

“智能桌面小咪”适合作为参考整机和消费产品名；正式印刷、上架或招商前应完成商标
检索，重点排查与现有智能终端品牌的近似风险。B2B 方案可以采用更稳定的双层命名：

- 产品名：智能桌面小咪 / Smart Desktop Mimi。
- 解决方案名：Mimi AI Desktop Solution。
