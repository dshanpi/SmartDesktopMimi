# 调试与验收资料

本目录保存“智能桌面小咪”硬件调试和界面验收所需的可公开维护资料。

- `kvm-pointer-calibration.png`：浏览器相对鼠标与 Windows 实际鼠标位置对比。
- `a133-en-us-20260906/`：英文桌面、AI、Wi-Fi、蓝牙、视频、OTA、HDMI MCP
  等页面的板端 framebuffer 验收截图。
- `../public-assets.json`：可发布截图的来源、许可证和 SHA-256 清单。

未纳入的本地产物包括原始/压缩 framebuffer、包含编译输出或嵌套 `.git` 的旧归档，
以及任何 Tuya UUID/AuthKey/SN、模型 API Key 或临时 SSH 凭据。
